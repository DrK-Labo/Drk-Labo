## Books

### Rustで作るSchemeインタプリタ

Rustで約1,000行のSchemeインタプリタを実装する、500ページ超の実装本。字句解析・構文解析・評価器・REPLを一歩ずつ組み立てながら、所有権やenumといったRustの特徴を「なぜその形で設計されたのか」が腑に落ちる文脈で体感する構成です。後半ではメタ循環評価器、レキシカルスコープ、クロージャといったCSの古典的テーマを動くコードとして再構成します。

**[Amazon Kindle で見る →](https://www.amazon.co.jp/dp/B0GX2VM5W5)**

対象読者: 何らかの言語で関数・分岐・ループを書いた経験がある方。Rust未経験でも、必要な文法は本書の中で段階的に導入します。

> *Building a Scheme Interpreter in Rust — a 500+ page implementation book in Japanese. Builds a working Scheme interpreter in roughly 1,000 lines of Rust, with ownership, enums, and pattern matching introduced where the implementation demands them.*

## プロフィール / About

大学院計算機科学専攻の博士課程で学び、UNIX系OSの環境で育ちました。論理型言語・関数型言語・手続き型言語からアセンブラまで、さまざまな言語処理系のインタプリタ・コンパイラの実装経験があります。その後、大企業の大規模開発プロジェクトのアーキテクチャ設計に携わりました。

「自分の手で動かすことで、はじめて本当に理解できる」という信念のもと、コンピュータサイエンスの古典的な概念を、新しいプログラミング言語で再構成するというコンセプトの著作を始めました。
